⚑ Where the map is thin today

Every address above answered a live check — nothing is broken. But seven spots would genuinely confuse a first-time visitor, and each has a small fix.

⚑ Agentix sounds like Agent Studio

agents.suedeai.ai (Agent Studio — where agents get built and launched; the one that matters) and agentix.suedeai.ai (a portfolio tracker that only watches earnings) get mistaken for each other constantly. Someone looking to deploy an agent who lands on Agentix hits a dead end.

Easy fix — one line on each: Agentix says “build agents at agents.suedeai.ai”; Agent Studio says “track earnings at agentix.”

⚑ Two things are named “Suede Social”

suede.social (the gear magazine) and social.suedeai.ai (the creator network, which also shares its name with the iOS app) are different products with nearly identical names. The single most confusing pair on the map.

Easy fix — give each homepage a one-line pointer to its sibling.

⚑ There are two ecosystem hubs

hub.suedeai.ai and hub2.suedeai.ai both present themselves as “the ecosystem map.” A visitor who lands on the wrong one can’t tell which is current.

Easy fix — pick one as canonical and forward the other to it.

⚑ The three front doors never introduce each other

Someone on suedeai.org doesn’t learn that suedeai.ai is where the product lives, and vice versa. Each door reads like the only door.

Easy fix — a shared one-line strip on all three: “the product (.ai) · the story (.org) · the index (hub).”

⚑ The master domain list speaks SEO, not human

jcinvestmentgroup.ventures/domains describes itself as a “controlled routing layer” for “authority concentration.” Accurate — and unreadable for a normal visitor. Its nav also promises Founder, Press, and Contact sections with little visible content behind them.

Easy fix — keep that page for search engines and link here for humans.

⚑ docs.suedeai.ai doesn’t answer

The developer documentation lives on GitHub (Suede-AI/suede-docs), but docs.suedeai.ai didn’t respond to a live check. The one address a developer would guess first is the one that’s dark.

Easy fix — point docs.suedeai.ai at the GitHub docs or the hub’s Developers section.

⚑ The hub’s numbers need translation

“7 groupings · 62 surfaces · 22 endpoints · 5 apps · 2 tokens” is impressive to insiders and meaningless to newcomers — the exact audience a hub exists for.

Easy fix — one sentence under the stats: “62 places you can visit, 22 services agents can pay to use, 5 phone apps.”
