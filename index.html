⚑ Where the map was thin — and what changed

The July 3 compile flagged nine spots that would genuinely confuse a first-time visitor. On July 4 all nine were fixed and re-verified live. The ledger, kept for the record:

⚑ Agentix sounded like Agent Studio

agents.suedeai.ai (where agents get built) and agentix.suedeai.ai (the earnings tracker) were mistaken for each other constantly.

Fixed July 4 — each now says it on its own page. Agent Studio: “This is where you build and launch agents.” Agentix: “This is the earnings tracker. To build and launch an agent, go to agents.suedeai.ai.”

⚑ Three things named “Suede Social”

It turned out to be two, not three: suede.social and social.suedeai.ai serve the exact same website, plus the separate Suede Social iOS app (App Store id6770668793).

Fixed July 4 — the website footer now says the two addresses are one place and links the iOS app’s own listing; this map’s cards above were corrected to match.

⚑ There were two ecosystem hubs

hub.suedeai.ai and hub2.suedeai.ai both presented themselves as “the ecosystem map.”

Fixed July 4 — hub2.suedeai.ai now permanently forwards (308) to hub.suedeai.ai. One hub.

⚑ The three front doors never introduced each other

Someone on suedeai.org didn’t learn that suedeai.ai is where the product lives, and vice versa.

Fixed July 4 — all three doors now carry the same one-line strip: the product (suedeai.ai) · the story (suedeai.org) · the index (hub.suedeai.ai).

⚑ The master domain list spoke SEO, not human

jcinvestmentgroup.ventures/domains described itself as a “controlled routing layer” for “authority concentration” — accurate, and unreadable for a normal visitor.

Fixed July 4 — that page now says it plainly: “For a plain-English version of this list, see map.suedeai.ai.” Search engines keep their version; humans get this one.

⚑ docs.suedeai.ai didn’t answer

The developer documentation lives on GitHub (Suede-AI/suede-docs), but docs.suedeai.ai — the one address a developer would guess first — was dark. No DNS record existed.

Fixed July 4 — the DNS record was added and docs.suedeai.ai now serves a pointer page to the GitHub docs.

⚑ The hub’s numbers needed translation

“7 groupings · 62 surfaces · 22 endpoints · 5 apps · 2 tokens” was impressive to insiders and meaningless to newcomers.

Fixed July 4 — hub.suedeai.ai now says it under the stats: “In plain English: 62 places you can visit, 22 services agents can pay to use, 5 phone apps, and 2 tokens live on Base.”

⚑ Two different API addresses

api.suedeai.xyz (what the hub and the agent catalog use) and api.suedeai.ai (what this map and suedeai.org pointed to) had drifted onto two different deployments of the same service.

Fixed July 4 — both addresses are now attached to the same project and always serve the same current deployment, verified byte-identical. api.suedeai.xyz is the canonical address agents use; api.suedeai.ai answers identically. No 301 was needed — redirecting a live pay-per-call gateway would break agent clients mid-payment.

⚑ The app roster didn’t match between sources

Two App Store listings had changed names, but hub.suedeai.ai and suedeai.org still showed older listing copy.

Fixed July 4 — both sites now show the current Apple names. This map’s own app list was already checked against Apple directly.
